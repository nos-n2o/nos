# nos-ospfv3 — OSPFv3 (RFC 5340) daemon

One `nos-ospfv3d --instance <name>` process per `Ospfv3Instance`, spawned by `nos-watchdogd` (same pattern as `nos-ospfd`; `docs/architecture/supervision.md`). It mirrors `ospf/` over real IPv6 raw protocol-89 sockets; read `ospf/CLAUDE.md` first for everything not called out here.

Details: behaviour and config in `docs/protocols/ospfv3.md`; how it is built (LSA types, wire mechanics, log lines, `ponytail:` ceilings, not-done lists) in `docs/protocols/ospfv3-internals.md`; e2e phases in `docs/e2e-phases.md`. This file keeps only the rules to respect when editing the crate.

## Layout

`socket`, `packet`, `lsa`/`lsdb`, `exchange` (pure), `link` (driver task + `LinkManager`), `reconcile`, `server`, `rib_push_client`, `link_client` (`ospf/src/link_client.rs` by `#[path]`, log prefix `crate::DAEMON`). DR/BDR election, the neighbor FSM, the LSDB and the whole DBD/LSR/LSU/LSAck exchange come from `nos-ospf-common` (`exchange` keeps only v3's closures and three stores). Acks are delayed and batched like v2 (`pending_acks`, `flush_pending_acks` on the 5s `RXMT_INTERVAL` sweep). The in-memory wire test seam (`link::LinkSocket`/`with_opener`) is `nos-ospfd`'s, and signs RFC 7166 trailers like the real socket.

## Rules

- **Stores**: one `Lsdb` per area plus one per link (`link_local_lsdbs`, Link-LSAs only, RFC 5340 §4.5.1) and one AS-scope `as_lsdb` for the router. `exchange::on_lsu_received` routes by the LSA's S2/S1 bits; a link's DBD summary, LSR answer and flood read its area store plus its own link store, so a Link-LSA never leaves the link it belongs to. SPF and `show ospfv3 database` merge the link stores back in. `Lsdb` itself is scope-oblivious.
- **Withdrawal** (#157): `LinkManager::originate_all` records the keys a tick originated, then `link::withdraw_undesired` prematurely ages every other live LSA of ours of an `OWNED_TYPES` type (never a Grace-LSA). A removed link's store is not swept.
- **Unknown LSA types** are kept as `LsaBody::Opaque(raw)` and re-encoded verbatim; scope uses the effective S2/S1/U bits, and S2/S1 `11` is discarded unacked.
- **Prefix options**: a received NU prefix is skipped by SPF and `intra_area_routes`; a loopback `/128` is originated with LA; P/DN are never set.
- **Link State IDs** of prefix-keyed LSAs are opaque: `LinkManager::lsid` allocates per `(type, prefix)` from a never-reused counter and `originate_all` prunes entries no longer originated (a restart or re-advertise's new IDs make `withdraw_undesired` flush the old ones); an Inter-Area-Router-LSA's ID is the ASBR's router ID.
- **SPF**: skips LSInfinity (`0xFFFFFF`) inter-area, external and ASBR-distance metrics; test-only `--originate-lsinfinity` makes the ABR/ASBR originate them (`ospfv3-lsinfinity`). Next hops from Link-LSAs, never the neighbor table; `run_dijkstra(.., links: None)` is distance-only (next-hop derivation would drop vertices from a non-root viewpoint). The external metric is the LSA's own (v2 adds a constant); own LSAs never route.
- **Instance ID** is header byte 14, after the kernel-filled checksum at 12 (stamping 12 corrupts it). The socket (`OspfSocket::signed`) stamps it with `packet::set_instance_id` before signing, and `link::run` drops a mismatch **before** `verify_trailer`, so another instance's packets never count as auth failures.
- **Checksum**: the kernel does it (`IPV6_CHECKSUM` offset 12, set in `socket::open`); an authenticated socket does not set it (RFC 7166 §2.2/§4.2). Linux IPv6 raw sockets deliver no IP header. Hop limit is 1 on every send.
- **Authentication** (RFC 7166, `packet.rs` `TrailerAuth::sign`/`verify_trailer`): `Ks = key || 0x0001`, `Apad` ends with the 16-byte IPv6 source, the AT-bit is set by `link::link_options` when the link has keys, the trailer lies outside the packet's `Length` (`decode_header` bounds every body by it), compare in constant time. The sequence counter lives in the socket (wall-clock floor); replay state is `NeighborInfo.last_crypto_seq` (per packet type) in `link::run`. `Md5` is rejected at commit.
- **Link state** (#276): same as `ospf/CLAUDE.md`'s; gating only in `reconcile::resync` (`link_client::gate`, a down device is left out of `desired_links`), ungated when never connected or `observed = false`. An unresolved VRF/address/bridge keeps the running link's value (`merge_running`, `LinkManager::running_config`) while the config still gives the attach point an IPv6 address. `LinkConfig.interface_id` is the stream's ifindex (`pick_interface_id`: stream, else `if_nametoindex`, else running), so a recreated device restarts the link. Log: `ospfv3 link resolution failed, keeping running link`.
- **BFD** (#288): `bfd_client.rs` is `ospf/src/bfd_client.rs` included by `#[path]`; sessions run between link-local addresses with `interface = kernel_interface`; `LinkManager::set_bfd` + `Host for LinkManager`, kill through `LinkEntry.bfd_tx`. Same rules as `ospf/CLAUDE.md`.
- **Graceful restart** (RFC 5187): same shape as v2 minus the IP-address TLV (`lsa::LSA_TYPE_GRACE` `0x000B`); only SIGTERM announces; nothing is aged on shutdown, the restarter resyncs cold.
- **DBD pagination**: `exchange::mtu_based_max_headers(LinkConfig.mtu)` (IPv6 40 + OSPFv3 16 + DBD 12 header bytes); `Ospfv3Profile.mtu` overrides the interface MTU (`reconcile::resolve_effective_mtu`); `--dbd-max-headers` is test-only.
- **LSU/LSR/LSAck split** (#807): every send goes through `link::{lsu,lsr,lsack}_packets` (`chunk_by_budget`, budget `mtu - 40 - 16 - 4 - trailer`, oversize LSA alone), one packet (own trailer sequence) per chunk; a new send site must use them.
- **Router-LSA split** (#853): originate side cuts links per area by the smallest-MTU budget (fragment IDs router-id, 0.0.0.1, ...); receive side unions all fragments; test-only `--router-lsa-max-links`.
- **Route push**: chunked like v2's (`rib_push_client::push`, test-only `--push-chunk`, #727).
- **Redistribution**: `Ospfv3Request::RedistributeRoutes` is `ribd`'s only (`server::allowed`); `reconcile::resolve_redistribute_policy` is a `ponytail:` copy of v2's.
- **Receive hardening** (#394): non-link-local sources are dropped in `link::run`; same neighbor cap and `warn_limited!` as v2. Dead timers are the 1s `sweep_dead_neighbors` on every network type (no p2p deadline); it removes idle `Down` entries and `handle_hello` evicts a same-address entry under a new router ID on p2p/p2mp (#957).
- Own LSA flooded back newer (§13.4, #731): same `mark_reflected`/`reoriginate`/`origination_pass` mechanism as `nos-ospfd`.
- **Not built**: stub areas/NSSA, area ranges, virtual links, RFC 5838 multi-AF, RFC 8362 sparse mode; list in `docs/protocols/ospfv3.md`.
- `reconcile_tests.rs` (#343) drives `resync`/`run` against `nos-test-support`'s fakes and a real `LinkManager` over `link::tests::wire`; attach points use `nostst0`, a device no host has, so an ungated link exercises the "not present yet" branch. The `cfg(test)` getters on `LinkManager` (`loopback_prefixes`, `bfd_wanted`, ...) are its read side.
- Verify kernel, IPC or wire changes with the matching `nos-e2e` phase (`ospfv3*`, `docs/e2e-phases.md`); `link::tests::abr_and_asbr_reach_across_areas` runs three routers over two areas on the in-memory wire.
- **Multicast flood** (#879): as `ospf/CLAUDE.md`: `flood_full_neighbors`/`flush_pending_acks` use `flood_dest` and `LinkSocket::send_flood` (`ff02::5`/`ff02::6`, one signed packet per chunk); unicast fallback on error; retransmissions, DBD/LSR, Grace stay unicast.
- **AllDRouters** (#854): `run_election` joins/leaves `ff02::6` (DR/Backup only, never p2p) via `OspfSocket::set_all_drouters`; logged on change, `ospfv3-dr` e2e asserts it.
